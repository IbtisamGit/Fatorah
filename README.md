# Fatorah

Fatorah is an intelligent, AI-powered personal finance and receipt management dashboard built with Next.js, Supabase, and Google Gemini. It takes the hassle out of expense tracking by turning raw receipts into actionable financial insights.

## Key Features

* **AI Receipt Scanner:** Instantly extract merchants, amounts, dates, and categories from receipts using Gemini's powerful OCR capabilities.
* **AI Financial Advisor:** Stop looking at boring charts. Fatorah analyzes your spending behavior, calculates your financial health score, flags anomalies, and provides personalized money-saving advice.
* **Privacy First (Manual Redaction):** Use our built-in HTML5 Canvas tool to seamlessly blur or blackout sensitive PII (like IBANs or IDs) directly in the browser before the image ever reaches the cloud or AI.
* **Smart Budgeting:** Track your monthly goals with precision using dynamic budgets and beautiful, custom-built SVG gauges.
* **Modern & Fast:** Built with Next.js 14 (App Router), Tailwind CSS, Recharts, and Supabase for a lightning-fast, glassmorphism-inspired UI.
